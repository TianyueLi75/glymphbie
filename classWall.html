Detailed Description

template<class Real>
class Wall< Real >

Wall class template for wall dynamics in glymphatic flow simulations.

Template Parameters
Real
Parameters
dtTime step size for wall dynamics.
center_outVector of outer wall center coordinates (size: 3 * number of grid points).
center_inVector of inner wall center coordinates (size: 3 * number of grid points).
radius_outVector of outer wall radii (size: number of grid points).
radius_inVector of inner wall radii (size: number of grid points).
Note
The wall dynamics (update of radii and their time derivatives) are to be defined in derived classes.
